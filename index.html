LEARN THE DIFFERENCE

01 Causal ordering

If sending message B depends on receiving message A, all processes must deliver A before B. Independent messages may appear in different relative orders.

02 Total ordering

All processes deliver all broadcast messages in exactly the same order, even if the messages were sent concurrently.

Simulation note: This is an educational, single-browser model. Total-order sequence numbers are assigned by one simulated coordinator; it is not a fault-tolerant distributed consensus protocol.
